# Cost/caching sources vs bundled guides, mapped onto this repo (2026-10-04)

**Sources read in full:** (1) blog "Reducing cost and improving performance with Claude Platform" (published 2026-09-08, re-run with Opus 5.5); (2) docs "Optimizing for cost and intelligence" (all sections plus the summary table and the 23 benchmark refs); (3) cookbook "Cost optimization on the Claude API" (prose plus the printed result cells). I fetched each with WebFetch, then pulled the raw source with curl (`docs…intelligence.md`, 878 lines; blog and cookbook HTML converted to text) to check every number. Raw copies are in `/tmp/capi-audit/raw/`.
**Caution, measured by comparing the WebFetch summary with the raw cookbook:** the WebFetch summary got the cookbook's final config wrong. It said "Sonnet medium + caching, $0.0500, 83%". The raw printed cells show Sonnet medium with an explicit system breakpoint at **$0.0223/task, 10/10**, which the cookbook calls a "13x reduction" from the $0.2906 Opus-high cold baseline. Every number below comes from the raw text.
**Guides compared:** `/tmp/capi-guides/shared/cost-optimization.md` (CO) and `/tmp/capi-guides/shared/prompt-caching.md` (PC). Where a sibling guide in the bundle already carries an item, I say so.

## (B) Every lever (pages + guides) mapped onto this repo

**Repo facts the mapping rests on:**
- **Quota, not dollars:** on the plan meter, cache reads weigh about 0 (bounded at ≤¼ of list price). **Cache writes and output drive the meter**; output is 32% of the meter proxy, memory files 22%. Source: measured in `docs/research/token-efficiency-2026-09-23/BASELINE.md` and `REPORT.md`.
- **TTL:** main threads get the **1h TTL automatically on a subscription**; agents get 5m. The measured miss breakpoint is ~65 min. Sources: `hooks/cache-expiry-warning.sh` header; OPPORTUNITIES N1.
- **Operator rule:** "never cut quality even for a disproportionate amount of token savings" (quoted in `hooks/cache-expiry-warning.sh`). Every tradeoff lever is therefore gated on an eval.
- **Always-loaded sizes (measured, `wc -c`):** `CLAUDE.global.slim.md` 27,432; `CLAUDE.rules.slim.10-session-close.md` 30,946; `.claude/CLAUDE.md` 6,778; `.claude/rules/agent-operating-lessons.md` 9,871; MEMORY.md 22,276 chars. The 78,337-char situational rules file is excluded live: `claudeMdExcludes` is set in `~/.claude/settings.json`, measured with `jq`.

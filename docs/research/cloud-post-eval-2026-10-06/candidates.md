## 4. Cheapest experiment for the highest-value candidate

Highest value: the cloud-gated repo hook (K03), because K01, K05 and K09 hang on the same unverified fact.
Experiment, described and not run: land one SessionStart hook that is silent unless `CLAUDE_CODE_REMOTE=true` and then prints a single line `CLOUD-HOOK-PROBE sid=… shallow=… depth=… gh=… bats=… shellcheck=… uid=… cc=$(claude --version)`; add one brief sentence asking the worker to quote that line in its first commit body, or to write `CLOUD-HOOK-PROBE absent`. Read it from the next organic fire's branch.
Cost: 0 extra sessions, 0 operator web actions. It settles hook loading on API-created sessions, the env var, today's clone depth, `gh` (F22), tool versions (F12), uid (F14) and the in-VM Claude Code version (the gap behind K07).
Limit: it needs one organic fire, and the dispatchable cloud queue is 0 today (R `a4` `cc-eligible sweep`).

## 5. Alternatives considered

- Routines as the whole dispatcher: ruled out by the missing ledger access, 30 fires/h, no idempotency key and credit ineligibility (K11, K27).
- Setup script instead of a hook: ruled out for now because it lives in per-account web state the repo cannot see (K14).
- Widening reach first: ruled out because supply is 1 open row; a wider classifier moves rows between venues on one quota pool.
- Claiming the credit by reflex: ruled out by the Usage Credit authorization in the terms against `usage_credits_authorized: false` (K10).

## 6. Adversarial pass

- "The hook is the fix." It is untested on our create path; the only support is indirect (VMs did run the project `/ship` command, so project config loads). If the probe says absent, K03 and K05 fall and K01 must key on the missing identity hooks instead.
- "61-84% conversion means the lane is healthy." n = 31; three instruments give 19, 23 and 26 returned (M `return.jsonl`; R `a1` sidecars and trailers). 17 of 26 trunk landings were docs-only (R `a1`).
- "K04 recovers five sessions." Upper bound. Three of nine conflict or supersede outcomes were our own preflight bug, and the 10-05 conflict came from our land price-out.
- "The private create is safe." Identical strings in two binaries show the CLI still uses those shapes, not that the server will keep accepting ours.
- Reader disagreement left standing: `gh` in the VM (repo first-hand 08-10 absent; docs present; 2.1.288 implies some images lack it).

Source: /tmp/s55/card.pdf (pdftotext -layout -f 55 -l 72) and figures /tmp/s55/figs/fig-061..071-*.png read with vision.
Scope notes:
- Pages 55-72 contain NO per-effort-level results, NO cost or token data, and NO Fable 5.1 comparator. Every chart compares six models: Mythos 5, Sonnet 5, Opus 5, Mythos 5.1, Opus 5.5, Sonnet 5.5. ✓

## Scope and method
- p.55 [scope] The alignment assessment is narrower because Sonnet 5.5 is not a frontier model. It focuses on acting against users, misleading users, high-stakes misuse, covering up, hard-to-monitor planning and eval-awareness. — "Sonnet 5.5 does not advance the frontier of our models' capabilities. Thus, we perform a narrower assessment" ✓
- p.55 [scope] Testing covers the model itself under various scaffolds, not specific product surfaces such as Claude Code. — "rather than on specific product surfaces such as the Claude chat interface, Claude Code" ✓
- p.55 [caveat] Internal testing runs at a smaller scale than deployment, so rare behaviours may be missed. — "behaviors that only emerge rarely or in hard-to-anticipate settings will be difficult for us to catch" ✓
- p.58 (+ p.63 caption) [method] The audit uses about 4,100 investigation sessions per model, built from about 1,850 mostly handwritten scenario seeds (each sampled 2-14 times), with a judge scoring several dozen dimensions. — "we conduct about 4,100 investigation sessions" ✎corrected (was: cited p.58 only; the "sampled 2-14 times" detail is in the Figure 6.2.1.B caption on p.63, not p.58)
- p.59 [method] The investigator can set the system prompt, simulate users and tools, adjust effort parameters and prefill. The target uses real tools on isolated sandbox machines, and every non-passive action must be approved by the investigator. — "Every action the target model attempts ... must first be approved by the investigator agent" ✓
- p.59 [method/claude-code] One agentic format uses complex harnesses, including the Claude Code harness, with optional internal Anthropic codebases and pre-seeded real internal sessions. Seeds continue real sessions that produced destructive or reckless actions. — "complex agentic harnesses (including the Claude Code harness)" ✓
- p.64 [safeguard] Footnote: partial-turn prefill is not generally available to external users for Opus 4.6 and newer models. — "partial-turn prefill is not generally available to external users" ✓

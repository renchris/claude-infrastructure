## Fix generations / mechanisms

1. **Self-close actuator** (`scripts/handoff-fire.sh self-close`, 07-02 → 09-09). Born with a whole-tree dirt refusal and a single close. Accreted gates, each a new refusal code: succession (07-13, exit 2/3), engagement + re-verify (07-24), live-teammate (07-25, exit 4), origin stamp (07-26), M3 mail (07-29, exit 6), pane_proof / identity / tenancy (08-05..08-10), composer guard via it2-kitty (08-07, exit 67), announce (08-09), UNLANDED/REMAINDER (09-09, exit 8). All of these are **new layers**. Root fixes: dd40eca3f (pgid kill), 9c0d42af0 (untracked dirt), 5515ac089 (identity, which also corrects 4cd42ec45's misdiagnosis).
2. **Post-close husk retry / page** (4cd42ec45, 07-25). A layer on a symptom. 5515ac089 says it never converged. In this slice it is the ancestor of the post-exit closer (`bin/cc-pane-close`, 10-01, out of slice).
3. **Recycle** (07-02 → 09-10). Rebuilt to depend on the pane surviving as a shell (c90c4cace). That dependency was then made universal (4065da386 runner invariant; c67bda626 reso-resume-one execs a shell).
4. **Reaper / teardown / teammate auto-shutdown** (07-14 → 09-07). The external closer. Has its own dirt rules (9c0d42af0, 5cd17f5da) and its own transport blindness (41d08635a).
5. **Close-attribution wrapper** (07-24 →). An observer layer. Its own bugs killed or pinned sessions (61101fb28, 1d77c6d69).
6. **Husk sweep** (09-04 →). A recovery layer added after husks exist. Its verdict mapping (dirty ⇒ RESUME) is inherited by the painter.
7. **In-pane verdict painter.** The rule is seeded 09-09 (43bc12679); the code arrives 10-22 (out of slice).
8. **Fullscreen guard.** No commits in this slice; the earliest are 10-19 (out of slice).

## Why it keeps coming back (evidence-backed)

1. **Every close is two acts, and the second one is designed to fail soft into a shell.** The session ends first, then a separate actuator closes the pane. The runner invariant "AFTER THE COMMAND, THE PANE BECOMES AN ORDINARY SHELL … never an exit" (4065da386) and c67bda626 (resumed panes exec a shell after the session "however that session ends") make a husk the default end state. Any refusal or failure in the second act therefore yields a husk.
2. **The same predicate is re-implemented per tool and the lesson does not travel.** Untracked dirt was fixed at three sites in 07-20 (9c0d42af0). Sibling dirt was fixed only on the teammate path in 08-04 (5cd17f5da: "The close then died ONE GATE LATER … re-convicted the member on a SIBLING's dirt"). cc-husk-sweep was then born on 09-04 with a whole-tree `status --porcelain` mapped to RESUME, and cc-pane-close:510 does the same. Commits say this outright: 37600948c ("That fix never reached the recycle watcher"), 17b8a859d ("still live on its twin"), 5c38ad5a0 ("three defects … each of which had already been fixed on a sibling path").
3. **Classifier and actuator use different state models.** 7c0492311: "Two sibling auditors over one state with two state models". b95775867: "the gate says REAP and the actuator refuses — rc=67 on every agent pane". On 2026-10-24 the same split appears three ways: cc-husk-sweep said COLLECTED, cc-pane-close refused, and cc-pane-verdict painted RESUME.
4. **Fixes add refusal layers keyed on what the tool can read, not on the harm it guards against.** fe7b675ad and b95775867 ("abstain-rule-can-retire-the-common-case"; the guard keyed on "can I read this pane?" instead of "could closing destroy text?"). 889c65600 (⛔ refusal "REFUTED FOR A STRUCTURAL REASON"). The rc70 fullscreen guard and gate 4 in the 10-24 incident follow the same pattern. Each layer fails closed, and failing closed on the close path produces a husk.
5. **Symptom layers get added on top of misdiagnoses.** The 4-retry husk page (4cd42ec45) was a fix for an "API blip" that was really a wrong-pane identity bug (5515ac089). The husk sweep (570c20375) and the painter seed (43bc12679) also deal with husks after they exist. Nothing in the slice was reverted, so these layers pile up.
6. **The terminal migration (iTerm2 → kitty, about 07-31) broke every caller's transport and identity assumptions one at a time:** acbaba85d (4/4 recycles failed), 255b3f665, 7c0492311 (kitty reuses ids), and 41d08635a (launchd reaper, five weeks later). Each caller was found and fixed separately.
7. **Verification targets lint or tests, not the pane outcome.** There are about 15 commits on one recycle retype site, each claiming to be "the last raw typed send" (08-25..09-03). 828816d40 is a gate that would have refused every close, hidden by a fixture. The commits record few live end-to-end checks that a finished pane actually ends closed.

# 09 — Prior art: existing Claude plugins vs our candidate capabilities

Date: 2026-09-26. Scope: overlap only (no BD/competitive research). Sources are read-only: local marketplace clone, GitHub API (`gh api`), web search.

## Headline

- **Crowded, skip or fold (8 of 18):** bash safety guard, write-backup guard, research fan-out, codex-security, visual-direction, plan conventions, beautiful-mermaid, permission harvest. A first-party or high-star community plugin already does the core job, or ours can't legally ship (visual-direction, and possibly repo-wiki).
- **Ship-worthy, where nothing comparable exists or ours is clearly deeper (5):**
  - manual-command-delivery
  - completion gating tied to the live git/DoD ledger (only if decoupled from our libs)
  - video-understanding's motion probes
  - keyless X-thread reader with a fallback ladder
  - bats-specific test-audit
- **Partial adds (5):** the add is real but narrow: Agent Teams operating rules, self-explaining explainer with measured gates, demo-recording (WebP), outbound drafting, repo-wiki.

## Gaps where nothing comparable exists

1. **Manual-command delivery.** No plugin or skill found for "hand the user one idempotent script with a `--confirm <target>` gate for irreversible steps". The pattern is generic and portable: 110 lines, 1 local reference.
2. **Completion gating on live repo facts.** Existing Stop gates (Sept 2026, all 0★) check "a verification command ran after the last edit". Superpowers' check is prose only. None blocks "done" on dirty, unlanded or unpushed work, remaining DoD items, or landed-but-not-deployed, with attribution to the session's own writes. The idea is uncovered, but it needs a from-scratch slim version: our hook is 1,287 lines on 9 libs.
3. **Motion analysis of video.** Ingestion (frames, sheets, ASR) is solved by claude-video (17.7k★) and claude-real-video (2.2k★). Nobody ships slit-scan, optical-flow or easing-fit probes for "how does this animate".
4. **Keyless X thread reader with a fallback ladder.** No notable (>50★) keyless skill walks self-reply threads in both directions with X Articles and an outage fallback. The known alternatives need the X API or a paid key.
5. **Measured quality gates for HTML explainers.** Generators exist (visual-explainer, diagram-design, playground). No word, contrast or frame-budget gate exists. Best shipped as a verifier that sits alongside them.
6. **Bats-specific test audit.** Upstream OpenClaw test-audit is language-agnostic, and wshobson's bats skill writes tests rather than pruning them. The bats-flavoured audit is a narrow gap.

## Blockers and uncertainties

- **Licence: visual-direction** depends on vendored ui.sh, which is sold under a paid personal or commercial licence. It can't go into a public plugin.
- **Licence: repo-wiki** says its prompts derive from Grok-Wiki `src/prompts/*`, and the AsyncFuncAI/grok-wiki repo has no licence (`gh api … license=NONE`). The npm package's licence is unverified.
- **Licence: codex-security** vendors Apache-2.0 code. Redistribution is permitted with NOTICE, but it's moot because it duplicates first-party `claude-security`.
- **Licence: test-audit** is adapted from OpenClaw. Upstream's licence wasn't checked, so confirm it and add attribution.
- **Coupling:**
  - agent-teams: 24 local references
  - research-subagents: 37 local references
  - demo-recording: 13 local references
  - permission-harvest: 11 local references
  - outbound-drafting: 6 local references
  - completion-assert: 9 `lib/*.sh` dependencies

  Counts are from `grep` over each `SKILL.md` or hook. These skills need de-coupling before any publish.
- **Unverified: the claude.ai/directory listing** (403 to curl). The official marketplace JSON (314 plugins at remote HEAD) is the proxy. The blog doesn't say whether the directory lists more than that JSON.
- **Unverified: the popularity of small competitors** (0★ repos) doesn't show how widely they're used. The mcpmarket and agentskill.sh aggregator pages weren't enumerated exhaustively.

## Alternatives considered and ruled out

- **Treating official-marketplace absence as "gap".** Rejected. The marketplace is vendor-heavy, and most generic workflow tooling lives on GitHub or in awesome lists, so every row was cross-checked there.
- **Counting `hyperframes`, `runway-api` or `slack-gif-creator` as video or demo overlap.** Rejected. They generate media and don't understand or record it.
- **Counting `ralph-loop` as a completion gate.** Rejected. It re-feeds the prompt in a loop and doesn't check whether the work is actually done.

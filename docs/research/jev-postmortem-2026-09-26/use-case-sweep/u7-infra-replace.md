What ties the ranking together: none of these is a live hook firing on a clock. The machine's recurring LLM spend on typed labels is **research and eval judges plus one dormant decider**. #1 and #2 are the only slots that spend Claude quota today on outputs that are already typed, and both come with gold sets on disk. So Jev can be validated against them with **zero new Claude calls**.

## Rejected candidates

- **Auto-mode classifier** (harness-internal, Sonnet). Its stage 1 is a boolean, but: its usage appears in no transcript (`measure/binary-and-cache.md:50`); it is Anthropic's injection-hardened safety control; its input is the whole transcript (≫16 KB); and the only way around it is a hook `allow` that bypasses every guard.
- **/goal evaluator** (harness Haiku). 662 evaluations in 14 d, 11.3/day since 09-17 (measured, `goal_status` attachments deduped by uuid, sentinels excluded). But its `reason` (p50 828 chars, measured) is generated text the agent consumes. The condition needs receipts from a transcript of up to ~100k tokens. Replacing it means rebuilding /goal.
- **research-decomposition-critic**: 15 spawns in 14 d including bench variants (measured). APPROVE/REVISE is typed, but the value is the named missing axes (text), and the critic Reads/Greps.
- **Verify/critic Workflows and Agents** (docs-sync-verify, kpanic PASS/FAIL, email-verify, o55-synth X/tie/Y, lr-instant-detect HOLDS/REFUTED). 212 Workflow runs, 110 with verdict enums (measured). Each label is earned by reading code or the web, and the Jev envelope forbids tool calls. The same applies to tokeff **F2** judges ("You may Read/Grep").
- **Dispatcher "POSTs every 300 s"** (`com.claude.dispatcher`, `bin/cc-dispatch`). It fires full work sessions (generation). It is not a judgment.
- **Anthropic liveness/entitlement probes** (`claude-accounts` `--wire` Haiku `:958`, `lr-probe.sh:69`, `handoff-fire.sh:10390`, `headless-precondition-probe.sh:26`). They test the account itself, and the response content is irrelevant.
- **session-search.py:672** Haiku query rewrite: generative, and gated on an API key.
- **Harness side requests** (titles, prompt suggestion, away summary, compaction): generated text.
- **cc-classify, cc-resume-classify, gate-classify**: structural or regex, with no LLM spend. Outside this lens; the prior wave covered them.
- **skill-creator `run_eval.py`**: it measures Claude's own skill triggering, so a substitute defeats the test.
- **Explore tier (Haiku)**: retrieval with tools.
- **reso repos `wiki/regen_page.py`, `refresh-uidotsh.ts`**: other repos, and generation. Pointer only.

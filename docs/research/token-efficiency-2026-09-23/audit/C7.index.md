# Lesson index

Proposed destination: `docs/lessons/INDEX.md`. One line per lesson: `symptom keywords | rule | body`. Grep it for the symptom or subsystem name (for example `grep -i pipefail docs/lessons/INDEX.md`) and open the body before relying on the rule. `mem/` stands for `~/.claude/projects/-Users-chrisren-Development-claude-infrastructure/memory/`. Lessons that apply to most sessions stay resident in `.claude/rules/agent-operating-lessons.md`.

Adding a lesson: write the body to `docs/lessons/<slug>.md` and add one line here.

Ceilings on `.claude/rules/*.md`: at 4 MiB the loader skips the whole file (guarded by `MEMORY_RULES_HARD_CAP` in `bin/cc-memory-rotate`). The startup size warning (150k chars) and the rotor's `MEMORY_RULES_WARN_CAP` (40000) truncate nothing; the cost they report is context budget.

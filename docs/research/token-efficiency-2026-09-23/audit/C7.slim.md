# Always-loaded project rules

This file loads into every session in this repo. It holds only lessons that apply to most sessions here or prevent a costly mistake nobody would think to look up. Every other lesson is one line in `docs/lessons/INDEX.md` (`symptom keywords | rule | body`).

Grep `docs/lessons/INDEX.md` for the symptom or subsystem name before you diagnose a failing test, gate, hook, land or fired session; design a detector, fixture, gate or measurement; kill processes or delete a worktree, branch or directory; bulk-retire, file, close or re-land a backlog row; fire a session; resolve a merge conflict; write shell that parses command output; or edit a document that carries file:line citations.

Adding a lesson: write the body to `docs/lessons/<slug>.md`, then add its line to `docs/lessons/INDEX.md`; add a bullet here instead only if it meets the bar above. A bullet states its rule, not a topic label, and links its body as `../../docs/lessons/<slug>.md` (a body still in the memory directory keeps its `~/.claude/projects/...` path). Rewrite a bullet to fit rather than truncating it. At the land gate `scripts/rules-hook-budget-lint.sh` refuses a bullet here that links `.`, exceeds 420 bytes (`wc -c`), or shares a link target with another bullet.

`hooks/memory-nudge.sh` and the `hooks/lib/memory-index-budget.sh` deny text still say to put a new rule's hook line here, and `bin/cc-memory-rotate` / `hooks/memory-index-drain.sh` append evicted MEMORY.md lines here under `<!-- routed … -->`. Apply the bar above to those too: a line that does not meet it goes to `docs/lessons/INDEX.md`. A size warning on this file: see the ceilings note at the top of `docs/lessons/INDEX.md`.

## Landing, shared worktrees and destructive actions

- [Ship owns the tree](../../docs/lessons/never-write-a-tracked-file-while-ship-is-in-flight.md) — while /ship runs, do not write tracked files in its worktree (that re-arms its rebase) or remove the worktree (its git calls then exit 128). Before deleting any directory, check which process was launched from it.
- [Never wrap /ship in your own timeout](../../docs/lessons/never-wrap-ship-in-your-own-timeout.md) — ship-land bounds itself and can run long under lock contention; run it unbounded and read its own verdict.
- [Landed ≠ tested](../../docs/lessons/a-landed-verdict-is-not-a-tested-verdict.md) — ship-land skips its smoke past a load ceiling and still pushes (`behaviorally UNGATED`); read the smoke line and run your diff's suites yourself.
- [Gate refusal ≠ gate result](../../docs/lessons/a-gate-refusal-is-not-a-gate-result.md) — a bats run that refuses, or that cc-bats defers, prints no TAP lines and exits 0; check the `1..N` plan line before trusting a `not ok` filter. Your own background gate holds a concurrency slot.
- [Gate invocation is contract](../../docs/lessons/a-gates-invocation-is-part-of-its-contract.md) — grep a gate for its literal command before checking locally. The land gate runs bare `shellcheck` (ship-land.sh:3258): `-S warning` hides info findings and `-x` hides SC1091; annotate every code a line can emit.
- [Soft reset onto a moved ref reverts](../../docs/lessons/soft-reset-onto-a-moved-ref-reverts-the-difference.md) — `git reset --soft origin/main` after trunk moved commits a revert of siblings' landed work; squash by rebase and read the file list of `git show --stat` for every squash.
- [Deployment interpreter ≠ yours](../../docs/lessons/the-deployment-interpreter-is-not-the-one-on-your-path.md) — launchd, cron and CI resolve `#!/usr/bin/env bash` against their own PATH (launchd gets /bin/bash 3.2); run what they execute under that interpreter in its suite, since a parse check misses runtime-only breaks.
- [Census misses the owner](../../docs/lessons/a-cwd-census-cannot-see-a-worktrees-owner.md) — a wave lead owns its worktrees from the repo root, so a cwd census shows them ownerless; require a positive owner signal (a recent commit, the branch namespace) before touching another session's branch.
- [Landed ≠ nothing in hand](~/.claude/projects/-Users-chrisren-Development-claude-infrastructure/memory/landedness-over-commits-is-blind-to-staged-content.md) — commit-landedness ignores staged and untracked bytes; before deleting a worktree or branch, check each path by content.
- [Empty selector is a universal selector](../../docs/lessons/empty-selector-is-a-universal-selector.md) — `VAR=x cmd` binds VAR for that command only, so a later pipeline stage reads it empty and an empty pattern matches every line; assign at shell level, and run the census alone and count its rows before any kill loop.

## Briefs, goals and filed rows

- [Subagent cannot answer a prompt](../../docs/lessons/a-subagent-cannot-answer-a-permission-prompt-so-a-prompt-trigger.md) — a subagent cannot answer a permission prompt, so a prompt-triggering command in its brief hangs like slow work; ban such commands by name in the brief, with the reason.
- [Probe writes into a live session](../../docs/lessons/a-research-probe-that-drives-real-ui-writes-into-the-operator-s.md) — "read-only" in a brief stops file edits, not actions that move or drive a live target; name and forbid those (a `test_*` entry point is not a read).
- [In-process agent caps at 100 turns](../../docs/lessons/in-process-agent-stops-at-100-turns-the-same-agent-in-a-workflow.md) — an in-process Agent stops at its maxTurns and reports normal completion with partial work; size briefs to fit, require incremental writes, and resume with SendMessage rather than re-firing.
- [Unreachable goal never clears](../../docs/lessons/a-goal-condition-containing-an-operator-only-act-never-clears.md) — a /goal condition that needs an operator-only act (a credential, a consent, loading a daemon) blocks forever after the reachable work is done; end the condition at what the agent can reach.
- [Arming ≠ mootness](../../docs/lessons/arming-and-mootness-cannot-share-one-falsifier.md) — a `--falsifier` exiting 0 closes its row as no longer needed, so a probe that detects a precondition arriving closes the row the moment it becomes actionable; read exit 0 as a sentence about the row before storing it.

## Reasoning

- [Turn adjacency ≠ elapsed time](../../docs/lessons/turn-adjacency-is-not-wall-clock-adjacency.md) — the model infers "just now" from turn position, which can be hours wrong; measure with date, stat or etime before a duration sets a verdict, and read the subject's own printed verdict first.
- [Narrated verdict ≠ computed](~/.claude/projects/-Users-chrisren-Development-claude-infrastructure/memory/narrated-verdict-is-indistinguishable-from-a-computed-one.md) — a conclusion echoed into a command's output reads back as that command's result; have the shell compute the claim (a counter or exit code) and read that.
- [Own records ≠ the world](../../docs/lessons/an-absence-in-your-own-records-bounds-the-records.md) — negative searches of stores we write (config, mailbox, archive) show only that we have no record; search a store we do not write, usually the public web, before saying there is no way.

# A reader that cannot prove delivery must not consume

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

[A reader that cannot prove delivery must not consume](.) — 2026-09-10, cc-backlog `0366d5cc7b87` (landed): a mailbox consumer advanced `.seen` AND `.acked` to EOF as an inseparable part of PRINTING, so a peer ping was marked fully read while its body reached nobody — measured `102.seen` = `102.acked` = 215 over a ~4000-word HANDOFF-PING that rendered nothing, recovered only by reading the box by hand. 🚨 **This is a WORSE shape than losing the message**: an UNREAD line is still pending and the next drain shows it, whereas a CONSUMED line is indistinguishable from one already handled and no reader will ever surface it again — so the failure is silent in the one direction that reads as agreement, and a lead that misses a link simply never answers. ⇒ **separate "I emitted it" from "a reader got it", and let only the second advance a shared cursor.** For `hooks/mailbox-drain.sh` the two coincide (its stdout becomes the turn's `additionalContext`); for a background watcher they do not, and every consumer should be asked which it is. **The authorizing belief lived in a COMMENT and nothing executed it** — *"our stdout rides the harness task-completion notification → a reliable delivery the model reads"* — same family as [[checker-population-rests-on-an-untested-belief]]. Measured, a backgrounded Bash task completes with a `<task-notification>` carrying a summary, a status and an output-file PATH: probe tokens on stdout **and** stderr appeared in NEITHER, at exit 0 and again at exit 2, so the drop is not conditioned on status and `verdict=` tokens are not a delivery channel. **The cited evidence was real and about a DIFFERENT TRANSPORT** — the doc measured an `asyncRewake` SessionStart HOOK, whose stderr genuinely does ride into a system-reminder, and that finding was carried across to the Bash-tool background path where it does not hold; when a comment cites a measurement, check that the thing measured is the thing being done. Three companions, each separable: (a) **a test can PIN the defect** — `F6a`'s `# and advances the shared cursor on fire` and `F-3`'s `# promoted by our reliable delivery` both asserted the bug, so the fix reddened the suite and the reds are the FINDING, not a regression (invert in place, never delete: the assertion is the record of what was believed); (b) **retiring a contract needs its subject named** — the rc-2 cursor-write escalation was deleted because a path that writes no cursor has no write to fail, and the case was repointed at the degrade path rather than dropped, so a future reader can see the escalation stopped existing; (c) **the obvious guard edit was the trap** — re-gating `_have_lib` on the NEW function looks right and silently drops the whole window to the lib-free baseline during live-layer convergence, because a per-file-symlinked binary routinely runs against an older lib; branch at the CALL SITE and make the invariant the property (*body delivered, no cursor written*), never the function name. Two instrument scars worth the line: a mutant anchored on a non-unique string applied to NOTHING and the suite's 4/4 green proved nothing (`assert count==1`, and print what changed); and a mutant written as `if false; then <take>` forced the SAFE fallback branch, so it survived — **a mutant must remove the cure, not merely disable one arm of it.**

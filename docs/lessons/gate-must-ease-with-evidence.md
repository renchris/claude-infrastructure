[Gate must ease with evidence](../../../../.claude-quaternary/projects/-Users-chrisren-Development-claude-infrastructure/memory/acceptance-gate-must-be-monotone-in-evidence.md) — 2026-09-08 · landed f229870cc: an acceptance gate can move the OPPOSITE way from the estimator it guards. `hook-dispatch-bench.sh` certified a run on `max/min > 2.5` over its per-cycle ratios — and the RANGE of a sample is non-decreasing in n, so every added cycle could only widen it while the median converged. The bench printed "re-run … with more cycles" as the remedy for a spread failure, and the research doc prescribed the same remedy for certifying the one live result the rig ever produced. Measured, 2,000 replicates/point from ONE UNBIASED distribution at the rig's own noise: P(certify) 51.7% → 19.2% → **0.0%** at 3/10/40 cycles while median error fell 0.244 → 0.071. The estimator converged and the gate diverged, so certification was unreachable BY COLLECTING DATA — the only lever its operator has — and the rig read as merely noisy rather than broken. ⇒ **For any gate deciding whether a number is quotable, ask whether P(pass) RISES with n under a true null.** If it falls, the statistic is a property of the SAMPLE (range, min, max, any extremum) where it had to be a property of the ESTIMATE (a CI, a standard error). Fix: the distribution-free sign-test interval `[R[k], R[m+1-k]]` at `1 - 2*P(Bin(m,1/2) <= k-1)`; positive-control its empirical coverage against nominal before trusting it, and guard the arithmetic (`2^m` is +inf from m=1024, and the exact branch then computes inf/inf, picking the NARROWEST interval and labelling it `nan%`). **Corollary: repairing the gate can settle the question with NO new measurement** — re-read under the interval, the run withdrawn as "directional, not certified" gave a 94% CI of 2.10..6.43 excluding 1.00 against a control CI of 0.29..1.51 containing it. The sign had been established for a month; only the gate could not report it. Re-analyse what you already have before commissioning the re-run.

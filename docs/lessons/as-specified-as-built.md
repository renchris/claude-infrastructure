# As-specified ≠ as-built

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

[As-specified ≠ as-built](.) — 2026-09-09, exhaustive-drive W3-B1 (landed 889c65600 + f6ee42ea0): **a W2 measurement that SPLITS — some arms confirmed, one refuted — produces an implementation that is deliberately NOT the rule the instrument priced, so re-running that instrument to certify the fix measures a program nobody shipped.** W2-B1 priced a self-close refusal as `📦 ∨ ⛔ ∨ REMAINDER≠0` and refuted the `⛔` arm (3/44 fires, all three legitimate retires — `BLOCKED` counts class-C packets THIS SESSION filed, and on a FIRED PEER filing the operator's decision IS the deliverable, so the polarity is inverted by construction, not by luck). W3 therefore shipped `UNLANDED>0 ∨ REMAINDER≠0` with `⛔` exempt; the brief's own re-run instruction named the OLD mode, which would have reported `2/41 REFUSED` for a gate that refuses **0**. ⇒ **when an implementation intentionally deviates from the measured rule, add an `--as-built` mode BEFORE re-measuring, keep the readings side by side (rung 7.3% · as-specified 4.9% · as-built 0.0% — their disagreement is the finding), and pin the fixtures whose verdict the deviation CHANGES** so a later edit to the shipped predicate cannot silently drift from the instrument that certifies it. **Second half, separable and the reason to build the mode even when you doubt it: a new consumer of an existing parser is a free test of that parser, and the consumer that reads MORE fields reaches bugs the short-circuiting one structurally cannot.** The default mode returned REFUSE on `RUNG ∈ {📦,⛔}` *before* reading any numeric field, so it never exercised the field path; `--as-built` reads only fields and immediately failed its own `RUNG=📦 UNLANDED=3` fixture — `_texts` re-dumps the `toolUseResult` dict and un-escapes its newlines, so the LAST line of an emitted block ends `…"}` (`UNLANDED=3"}`), which `int()` rejects and every numeric reader then silently scores **0**. Harmless while the numeric fields sit mid-block, not harmless the moment a block is truncated at one; the fixture hid it by putting the numeric field last, a shape production never has. **Third, mechanical and reusable: a function called inside a command substitution cannot hand a decider its parsed values** — every caller of `hf_ledger_stamp` runs it as `$(…)`, so a variable assigned there never escapes; the fields reach the refusal through an optional output-FILE argument, and that file is written on EVERY path including the three UNREAD returns with a `STAMP_READ=0/1` flag, because a refusal on a non-answer strands a pane on the instrument rather than on the work (10 of the 54 measured retires carried no frozen ledger at all).

# A row you FILE carries the same burden as a row you DRIVE — and one grep usually settles it

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

[A row you FILE carries the same burden as a row you DRIVE — and one grep usually settles it](.) — 2026-09-16, measured on my own filings in a single session: I filed three backlog rows from assertions I had not checked, and **two were refuted later the same session by ONE command each**. (a) `e18db748707d` claimed the land gate's hermetic `$HOME` clones "are NOT reaped", from a snapshot showing three on disk — but 9-10 lands were running concurrently, so those belonged to LIVE lands; my own land's final act was `rm -rf` on its own clone. A population snapshot read as a leak. (b) `3c3ef30e5517` claimed "cost consumers cannot price Fable 5.1", naming two files a synthesis agent had asserted were consumers; `grep -rln pricing_per_mtok bin/ scripts/ hooks/ lib/` returns **NOTHING** — the key has zero consumers, so the remedy would have been built for nobody. Worse, one "consumer" hit was `claude-accounts`' `cache_read`, **a function that reads a CACHE** — an identifier collision with token cache-reads, which is precisely where a census turns into a false positive. ⇒ **before `cc-backlog add`, run the one command that would refute the row**: does the named consumer actually read the named key; is the named population actually idle rather than mid-flight; does the identifier you grepped mean what you think in that file. A filed row is not a cheap parking space — it is a claim a future session will spend real time acting on, and this repo's own corpus already records the downstream shape (*a filed remedy is a hypothesis with the same burden as the diagnosis*; *an item's payload is its EFFECT*). The asymmetry that makes this worth a rule: refuting these cost ONE grep each AFTER filing, and would have cost the same ONE grep BEFORE — the only difference is whether a wrong claim spent time in the queue with my name on it. Companion, same session and the reason the second one slipped: **a claim inherited from a subagent's synthesis is not evidence, however confidently it names files and line numbers** — verify a delegated finding's load-bearing nouns yourself before you put them in a durable store.

# A mid-turn brief is invisible to the fired-peer detector

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

[A mid-turn brief is invisible to the fired-peer detector](.) — 2026-09-10, measured on this session: `handoff-fire.sh self-close --terminal` REFUSED a genuinely fired peer as an ORIGIN session, because it re-derives fired-peer status from the **FIRST user message** (the stamp-repair path, backlog `c163f42390a3`) and reasons that "a fire composes the self-retire trailer and the engagement marker together, so their absence is positive evidence that no fire composed this brief". That inference is sound about WHERE IT LOOKED and false about the session: the brief carried BOTH (`HANDOFF-ENGAGE-85657-1789006332-29964` + the ON COMPLETION trailer), but it arrived **mid-turn** — Claude Code delivers a message sent while a turn is running as an injection alongside a tool result, so the FIRST user message was an unrelated stale peer-mail notification that woke the pane minutes earlier. A dispatcher firing into an already-awake pane therefore produces a peer that cannot retire itself. ⇒ **do NOT reach for `--allow-origin-close`** (the refusal is right that the evidence is missing, and the override is the one action that cannot be undone): report, stay up, and let the operator close it — an origin session staying up costs a pane, while a wrong self-close costs the report. And when firing, remember the marker only counts if the brief LANDS FIRST in the target: a fire into a pane that is mid-turn silently forfeits the peer's whole self-retire contract. Same family as [[transplanted-session-loses-dispatch-identity]] — dispatch identity is reconstructed from a transcript position, so anything that moves the brief off that position erases it.

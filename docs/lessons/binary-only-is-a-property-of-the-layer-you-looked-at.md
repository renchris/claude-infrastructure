# "Binary-only" is a property of the layer you looked at

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

["Binary-only" is a property of the layer you looked at](.) — 2026-09-16, the kitty zero-shift title band: a fix that needs a C change reads as "lands at the next restart", and on a box whose terminal holds live agent sessions that reads further as "not today". Both readings were wrong, and the correction is worth carrying because the shape is common: **ask whether the runtime exposes an injection point for the same change at a scriptable layer, before pricing the restart.** kitty's `watcher` option is arbitrary in-process Python and loads into a RUNNING instance — `kitty @ launch --type=overlay --watcher <path> sh -c 'sleep 0.2'` — so the Python half of the patch (draw the title bar's rect over content row 1 instead of allocating it a row, which leaves `current_pty_size` unchanged and therefore never reaches `resize_child`) went live in an already-open terminal with zero rows lost and zero SIGWINCH, measured against the stock bar in the same session as the positive control. Two mechanical traps on that route, both measured: `--type=background` does NOT work (a background launch creates no Window, so `load_watch_modules` is never reached), and watcher modules are memoised BY PATH (`kitty/launch.py:523`), so re-injecting an edited copy needs a NEW path and a module-global "already installed" guard is useless — park the saved original on the CLASS instead, or the second injection wraps the wrapper. **Second half, and the one that decided the design: a C field's reachability from script is its READ SET, not its type.** `Window.padding` is written by one function and read by exactly four — the four mouse edge functions at `kitty/mouse.c:249-267` — and by NO rendering path, which makes it a pure hit-test inset Python can set: pushing the top inset back by one cell takes a band drawn over row 1 out of `contains_mouse()` and lets `mouse_region()` reach its title-bar arm, delivering the hand cursor and the native window drag with no C change at all (measured: zero changed pixels, hand photographed against an I-beam control). ⇒ before writing off a change as binary-only, grep the field's read sites and the runtime's plugin surface; "needs a rebuild" is a claim about where you looked.

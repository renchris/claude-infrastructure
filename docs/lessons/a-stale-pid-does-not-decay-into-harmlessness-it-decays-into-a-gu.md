# A stale pid does not decay into harmlessness — it decays into a gun aimed somewhere new

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

[A stale pid does not decay into harmlessness — it decays into a gun aimed somewhere new](.) — 2026-09-16, kitty-drag phase 3, measured twice in one afternoon. Every brief in the phase carried *"never signal pid 97084"*, naming the operator's live kitty. A kernel panic at 15:50 killed it, so from then on the constraint was **trivially satisfied while the real terminal was unnamed** — a refusal that reads as honoured precisely because its subject is gone. Corrected in place to pid 633. A second panic at 16:28 falsified that too, and this is the half worth carrying: **`ps -p 633` now returns `calaccessd`, the system calendar daemon.** The pid was not merely freed, it was REUSED by an unrelated live process, so within one hour a safety rule had turned from *pointing at the thing to protect*, to *pointing at nothing*, to *pointing at an innocent bystander.* ⇒ **Never key a refusal on an identity that a reboot re-issues** — pid, port, inode, session id, container id, ephemeral socket name. Key it on something the class OWNS: kitty names every live control socket `/tmp/kitty-<pid>`, so `scripts/kitty-drag-w4.sh` refuses any socket matching the `/tmp/kitty-*` glob and cannot go stale across a reboot, a restart, or a second instance. The general shape: prefer a predicate over the KIND of thing to a name for ONE instance of it. Two companions from the same hour: **(a) I polluted that very glob myself, twice** — first with `/private/tmp/kitty-dev` and `/private/tmp/kitty-482` compatibility symlinks, then by redirecting bats output to `/tmp/kitty-drag-arm.bats.tap`. Neither is a socket so no correct consumer is fooled, and a glob-only consumer becomes MORE conservative rather than less; but a namespace you have chosen as your safety predicate is one you must then stop writing into, and the temptation is invisible because the filenames look unrelated to the rule. **(b) The staleness is silent in the one direction that reads as compliance** — nothing errors, no gate fires, and the brief still contains a sentence that sounds like a guarantee. The only tell is to re-derive the identity at the moment of use, which is exactly what an identity-free predicate makes unnecessary.

# A research probe that drives real UI writes into the operator's live session

_Relocated VERBATIM from `.claude/rules/agent-operating-lessons.md` (always-loaded tier) — the rules file now carries the hook and links here. Nothing was shortened._

[A research probe that drives real UI writes into the operator's live session](.) — 2026-09-16, same wave, and it blocked the succession: a skeptic verifying the macOS drag path ran `kitty @ action test_dragging` against a live socket. That action is not a read — it begins a real drag-and-drop carrying kitty's own literal payload `This is a test drag of some basic text with the kitty logo as the drag icon.`, and the drop landed **in a live Claude Code composer**. Nothing errored; the text simply sat there unsubmitted. The cost surfaced only at `handoff-fire.sh --recycle`, whose composer gate correctly refuses to type `/exit` into a non-empty composer (a `/exit` MERGES with a held draft and submits the hybrid), so the phase succession was deferred on a pane whose draft no agent may clear: **auto mode's classifier denies an agent sending keystrokes to a LIVE session**, and the rail's own scrub is authorised only over residue it can attribute to its own paste receipt. Three correct guards, and the residue is still stuck. ⇒ **In any read-only research brief, name the side-effecting probes explicitly and forbid them against live targets** — "read-only" is understood as "do not edit files" and does NOT stop an agent from invoking an action whose whole purpose is to move something. A probe is read-only only if its NAME is; `test_*` and `debug` entry points routinely are not. ⇒ And when it happens: attribution is still establishable by CONTENT rather than by a receipt — the pasted string was a hardcoded literal in the subject's own source (`kitty/boss.py`), which no human types — but **proving whose text it is does not grant the ability to clear it**; that stays the operator's single keystroke. Prefer a sandbox instance for any action-class probe, and where the only honest target is the live one, hand the probe to the operator instead of firing it.

# Clean nulls can be one conjunction

[Clean nulls can be one conjunction](.) — 2026-09-16, the kitty title-band SIGSEGV: three sandbox arms each moved ONE variable off the dead instance's configuration and each returned a clean null — shipped harness (1 tab, visible) 12/12 pass · a second session's sandbox (1 tab, MINIMIZED) no crash · a variant with a second `new_tab` (2 tabs, VISIBLE) no crash. Read singly that is three exonerations and the feature looks safe; read together it says the remaining candidate is a **conjunction** (visible AND multi-tab AND injected-into-a-RUNNING instance), which a one-variable-at-a-time sweep cannot reach however often it runs. The tell is that each arm ALSO cleared a different single hypothesis — visibility is not the missing half (the 2-tab arm was visible), tab count is not either (that same arm had two tabs) — so the hypotheses were being retired one at a time while the conjunction survived untested. ⇒ when repeated single-variable probes all come back clean on a fault that DID happen, stop adding arms and instead hold EVERY known property of the failing configuration at its observed value simultaneously, then vary something else; and read the failure's own artifacts for those properties (here the unwatcher logged `relaid out 2 tab(s)`, naming the tab count nobody had varied). Extends [[control-fixture-must-reach-the-bugs-regime]] from one blind axis to a blind INTERSECTION.

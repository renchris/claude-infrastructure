[Retiring a population is not recovering its work](.) — 2026-09-10, the recovery half of cc-backlog `307fe7ab1e91` (landed with this note): the disposition lane did its job perfectly and **still left real work on branches nothing points at.** `cloud-retire-terminal.sh` is explicit that it "NEVER deletes a branch, a declaration or a byte" and that its `conflict` verdict means *the branch carries commits not on trunk*; retiring frees the ROW for re-dispatch, it does not land the CONTENT. So a cohort can read 100% disposed — measured `bin/cc-cloud list`, **270 of 270** declarations aged ≥17 d RETIRED, zero non-retired — while three files with live consumers sit on no branch of trunk: `tests/handoff-prompt-file-join.bats` (its branch is the subject of **blocked** row `6484a07b7221`, "re-land … ship-land could not complete and its author's pane may be gone"), `tests/capacity-ceiling-derivation.bats` (row `e981656df348` asked for exactly this derivation-control, then closed `done` on evidence about a *different* deliverable, `branch-prune-landed.sh`, after ~20 reopen/block cycles — recovered independently by a sibling as `766a09300` while this land sat in the queue, which reached the SAME supersession call and the SAME D7 re-anchoring below without coordination; two sessions converging on one call is evidence for it), and `docs/research/plan-open-falsifier-cannot-report-unaskable-2026-08-20.md` (the disproof that row `83f44615f0eb`'s "premise-retracted" evidence points at). ⇒ **after any bulk retirement, ask separately what the retired set was CARRYING** — `git cat-file -e origin/main:<path>` per path on each surviving branch, never `git cherry`, which flagged 26 where content-verification found 3 (*cherry + ≠ absence*). 🚨 **And the wanted half and the superseded half live in the SAME commit.** That first branch also carried a `scripts/lib/capacity-admit.sh` comment block, and trunk's version is **later and better** — it holds the 2026-08-20 `f944d6e3` finding the branch predates (an additional resident session moves 1-min runnable by ~0, so the INPUT is wrong, not the number) and deliberately cites the origin commit **by subject, saying "a land rebases"**. Restoring the branch's file wholesale would have reverted three weeks of trunk; take paths, never refs, and diff every path the branch touches that trunk already has. **Second companion, and the trap that nearly landed a regression: a recovered test ratchets the PROSE of the tree it was written against.** Its `D7` demanded `grep -q "0fc3a3d33"` — the origin commit **by sha** — which trunk had deliberately replaced with a subject citation for the reason our own corpus gives ([[cited-sha-may-not-survive-the-land]]); satisfying the stale test would have forced the repo to regress to the practice it had just outlawed, and its line-based `grep -vc 'used to read'` read a cosmetic two-line wrap as the defect returning ([[stale-assertion-becomes-an-inverted-guard]]). Re-key such assertions from WORDING onto FACTS, then prove the re-key is not vacuous with mutants — three here, run against this session's equivalent re-key before the sibling's landed (reintroduce the false claim outside the retraction · delete the retraction history · drop the measured incident value) all go red against a green control. **Third, the finding the recovery bought that the item never mentioned:** the recovered suite's one genuine red exposed a live trunk gap — `_resolved_prompt_file` read `PROMPT_FILE_ORIG`/`PROMPT_FILE` but never `RCY_PROMPT_FILE`, and the detached `__recycle` watcher re-execs the script with neither of the first two in scope, so all seven of its `emit_recycle_event` sites emitted `prompt_file:null`. Measured in `~/.claude/logs/handoffs.jsonl`: **19 of 19 `recycle-engaged` rows null against 28 of 30 for the foreground `recycle-intent`** — a split falling exactly on the watcher boundary, i.e. every successful in-place recycle joined to no brief, which is the one question the field exists to answer. ⇒ **a stranded test suite is an unrun instrument; running it is how you find out what drifted while it was stranded** — the value of recovering it is not the coverage, it is the verdict.
